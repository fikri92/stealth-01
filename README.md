**Nightvault** is a browser‑only, offline top‑down stealth game.  The player must
stealthily move through a vault, avoid guards' vision cones, use cover to break
line‑of‑sight, pick up a keycard and reach the exit without being caught.

* **No network** – all assets are static files.  It runs in a desktop browser.
* **3 screenshots** – `screenshots/1-start.jpg`, `2-play.jpg`, `3-end.jpg`.
* **Dossier** – `dossier.json` is generated by `main.ts`.
* **Node 22** – the entry program is `main.ts`.

**How to play** – open `game/index.html` in a browser, use WASD to move,
Shift to crouch, P to pause.  When the player is seen a red cone appears and
after a short grace period the player is caught.

**Goal** – reach the exit in the shortest time.
